## 🔥 The Problem

> **Real estate is one of the largest financial decisions of a person's life — yet it remains one of the most opaque industries in the world.**

Every year, lakhs of homebuyers in India pour their life savings into residential projects, only to face:

| Pain Point | Reality |
|---|---|
| 💸 **High Broker Commissions** | Buyers pay 1–3% brokerage fees with zero transparency into where that money goes |
| 🏗️ **Construction Opacity** | No reliable way to verify if a project is actually progressing on schedule |
| 📅 **Delayed Possession** | 60%+ of under-construction projects in India face possession delays of 1–5 years |
| 🚗 **Distance Barriers** | Buyers in Mumbai can't easily track a project in Pune they invested in |
| 📊 **No Reliable Comparisons** | No unified, unbiased tool to compare projects side-by-side on trust, quality, and delivery |
| ⚠️ **Builder Fraud** | Fraudulent builders collect money, stall construction, or disappear entirely |
| 🔇 **No Accountability** | Verbal promises made during site visits leave zero paper trail |

**The real estate market is broken not because of bad builders — but because of missing infrastructure for transparency and verification.**

NestVerify is that infrastructure.

---

## 🏠 What is NestVerify?

```
NestVerify = Real Estate Transparency Layer + Builder Accountability Engine + Buyer Empowerment Platform
```

NestVerify is a **trust-first real estate verification and transparency platform** that bridges the gap between homebuyers and builders through verified data, live construction tracking, and direct, accountable communication.

Think of it as:
- **GitHub for construction projects** — version-controlled, milestone-tracked progress
- **LinkedIn for builders** — verified profiles, track records, and reliability scores
- **Booking.com for real estate** — honest reviews, ratings, and comparison tools
- **Zoom meets accountability** — video calls with logged, timestamped conversation history

> NestVerify doesn't just list properties. It **audits them**, **tracks them**, and **holds builders accountable** — in real time.

## 💎 Why NestVerify is Different

Unlike portals like MagicBricks, 99acres, or Housing.com, NestVerify is **not a listing aggregator.** Those platforms are marketplaces for brokers. NestVerify is a **verification and tracking system** for buyers.

```
Traditional Platforms          vs          NestVerify
─────────────────────────────────────────────────────
Static listings                →    Live construction dashboards
Broker-driven discovery        →    Direct builder communication
No delivery accountability     →    Timeline tracking + delay alerts
No builder history             →    Verified track records & RERA check
Self-reported amenities        →    Community-verified reviews + Q&A
Zero post-booking support      →    End-to-end project lifecycle tracking
```

## ⚡ Core Features

### 1. 📊 Live Project Dashboard
> *The heartbeat of every listed project — updated in real time.*

- **Construction Progress Tracker** — Visual percentage completion with milestone breakdowns (Foundation → Structure → Finishing → Handover)
- **Timeline Comparison Engine** — Side-by-side view of promised vs. actual delivery schedule
- **Media Feed** — Builder-uploaded photos, videos, and drone footage with timestamps and GPS metadata
- **Milestone History** — Immutable, timestamped log of every project update (GitHub commits, but for buildings)
- **Weather & Delay Context** — Auto-contextual notes on delays due to weather, regulatory holds, etc.

---

### 2. 🛡️ Builder Verification System
> *Every builder on NestVerify earns their credibility — or loses it.*

- **RERA Verification** — Automated pull from RERA state databases to verify builder registration
- **NestScore™** — Proprietary reliability score (0–100) calculated from delivery history, reviews, legal status, and responsiveness
- **Past Project History** — Portfolio of completed/ongoing projects with verified delivery records
- **Legal Transparency Layer** — Publicly surfaced litigation history, notices, and pending cases
- **Verified Builder Badge** — Only awarded after document verification, not just self-registration
- **Response Rate & Responsiveness Score** — Builders who ghost buyers get penalized in rankings

---

### 3. 💬 Direct Communication Hub
> *No more middlemen. No more lost promises.*

- **Encrypted Chat with Builder Reps** — One-on-one, verified channels
- **Video Call / Virtual Meeting Scheduling** — Built-in calendar and video integration
- **Conversation Log Archive** — All chats are timestamped, searchable, and exportable as PDFs for legal use
- **Verified Contact Identity** — You always know you're speaking with an authorized representative
- **Response SLA Tracking** — Builders are rated on how quickly and completely they respond

---

### 4. 🔬 Smart Comparison Tool
> *Compare what actually matters — not just square footage.*

Compare any 2–4 projects across:

| Dimension | Metrics |
|---|---|
| 💰 **Pricing** | Base price, hidden charges, payment plans |
| 🏗️ **Construction** | Current progress %, delay history |
| 📍 **Location** | Connectivity, schools, hospitals, transit |
| 🛡️ **Builder Trust** | NestScore™, RERA status, delivery record |
| 🌿 **Amenities** | Verified vs. promised amenity comparison |
| 🗣️ **Community Sentiment** | Aggregate review scores, sentiment analysis |

---

### 5. 🥽 Virtual Experience Center
> *Visit a site from anywhere in the world.*

- **3D Walkthroughs** — Photorealistic floor plan walkthroughs of flats, common areas, and amenities
- **Virtual Site Visits** — 360° drone and ground-level virtual tours linked directly to the project listing
- **Location Intelligence** — Layered maps showing nearby infrastructure, development plans, and commute heatmaps
- **Flat Configurator** — Explore different unit types, layouts, and view corridors virtually

---

### 6. 🌍 Reviews & Community Layer
> *The voice of real buyers — verified, fair, and fraud-proof.*

- **Verified Buyer Reviews** — Only buyers who've registered interest or made bookings can leave reviews
- **Q&A Forum per Project** — Crowdsourced answers, moderated for accuracy
- **Builder Response Feature** — Builders can officially respond to reviews on the record
- **Review Fraud Detection** — AI-powered detection of fake or incentivized reviews
- **Community Upvote System** — Most helpful questions and answers surface to the top

---

### 7. 🔔 Smart Alerts & Notification Engine
> *Never miss a thing. Always stay informed.*

- **Construction Milestone Alerts** — Get notified when a project reaches a new phase
- **Delay Detection Notifications** — Automatic alerts if a project falls behind promised timelines
- **Price Change Tracker** — Real-time notification when builder updates pricing or payment plans
- **Legal Status Alerts** — Instant notification of RERA notices or litigation filings against a project
- **Personalized Watchlist** — Follow projects the way you follow stocks or repositories
- **Digest Summaries** — Weekly/monthly project health reports via email or in-app

---

### 8. 🔐 Admin & Verification Engine
> *The infrastructure of trust behind everything.*

- **Multi-Tier Approval Workflow** — New listings go through document verification before going live
- **AI Fraud Detection Pipeline** — Identifies suspicious listing patterns, fake reviews, and anomalous builder behavior
- **Document Vault** — Secure storage and verification of RERA certs, building plans, and approvals
- **Dispute Resolution System** — Structured buyer-builder dispute escalation with admin mediation
- **Audit Trail Dashboard** — Complete history of all admin actions, approvals, and flags


**Key Architectural Principles:**
- **Event-Driven Updates** — Construction milestones trigger cascading notifications
- **Immutable Audit Logs** — All updates are append-only for accountability
- **Multi-Tenancy** — Builders, buyers, and admins operate in isolated permission contexts
- **Media Pipeline** — Drone footage and photos go through compression, metadata stripping, and geo-verification before publishing

## 🛠️ Tech Stack

### Frontend
| Layer | Technology | Why |
|---|---|---|
| Web Framework | **Next.js 14** (App Router) | SSR for SEO, fast page loads, great DX |
| Mobile | **React Native + Expo** | Single codebase, native performance |
| UI Components | **shadcn/ui + Tailwind CSS** | Composable, accessible, highly customizable |
| State Management | **Zustand + React Query** | Lightweight global state + smart server sync |
| 3D / Virtual Tours | **Three.js + React Three Fiber** | 3D walkthroughs and virtual tours |
| Charts & Dashboards | **Recharts + D3.js** | Construction timeline visualizations |
| Maps | **Mapbox GL JS** | Rich location intelligence layers |
| Real-time | **Socket.io** | Live construction updates and chat |

### Backend
| Layer | Technology | Why |
|---|---|---|
| API Framework | **NestJS** | Structured, scalable, TypeScript-first |
| Auth | **NextAuth.js + JWT** | Flexible auth with role-based access |
| ORM | **Prisma** | Type-safe database access |
| Queue System | **BullMQ + Redis** | Async media processing and notifications |
| Search | **Elasticsearch** | Fast project search and filtering |
| WebSockets | **Socket.io** | Real-time dashboard and chat |

### Infrastructure & Data
| Layer | Technology | Why |
|---|---|---|
| Primary DB | **PostgreSQL** | Reliable relational data for transactions |
| Document Store | **MongoDB** | Flexible schema for media and reviews |
| Cache | **Redis** | Session management, rate limiting, pub/sub |
| File Storage | **AWS S3 + CloudFront** | Scalable media delivery globally |
| Video Processing | **FFmpeg on Lambda** | On-demand video compression and streaming |
| Hosting | **AWS / Vercel (hybrid)** | Scalable infra with edge delivery |
| CI/CD | **GitHub Actions** | Automated testing and deployments |
| Monitoring | **Sentry + Datadog** | Error tracking and performance APM |

## 🚀 Getting Started

### Prerequisites

```bash
Node.js >= 18.x
PostgreSQL >= 15
MongoDB >= 6.x
Redis >= 7.x
```

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/pandeylakshya207-max/NestVerify.git
cd NestVerify

# 2. Install dependencies
npm install

# 3. Set up environment variables
cp .env.example .env
# → Fill in your DB credentials, API keys, and secrets

# 4. Run database migrations
npx prisma migrate dev

# 5. Seed initial data (optional)
npm run db:seed

# 6. Start development server
npm run dev
```

### Environment Variables

```env
# App
NEXTAUTH_SECRET=your_nextauth_secret
NEXTAUTH_URL=http://localhost:3000

# Database
DATABASE_URL=postgresql://user:password@localhost:5432/nestverify
MONGODB_URI=mongodb://localhost:27017/nestverify
REDIS_URL=redis://localhost:6379

# Storage
AWS_ACCESS_KEY_ID=your_access_key
AWS_SECRET_ACCESS_KEY=your_secret_key
AWS_S3_BUCKET=nestverify-media
AWS_REGION=ap-south-1

# Maps
NEXT_PUBLIC_MAPBOX_TOKEN=your_mapbox_token

# External APIs
RERA_API_KEY=your_rera_api_key
```


| Prefix | Use For |
|---|---|
